About

Vanish

-

An on-device Windows application auditor and deep uninstaller. It shows its work, undoes its damage, and waits for your word.

Nothing dies on the first blow

Files are moved to a quarantine vault and registry keys are exported to a .reg restore manifest before removal. Everything stays reversible until you explicitly say otherwise.

Audit before power

Unelevated, Vanish is fully useful: it lists, scans, explains and reports. It never pretends it can act. Elevation is a separate, explicit step.

The machine is a vault, not a wire

Zero network activity at runtime. No telemetry, no cloud lookups, no update pings. The icon set and typography are local, so nothing is fetched even for decoration.

What it does not do

It is not an antivirus and gives no threat verdicts. It cannot promise a complete rollback: asynchronous installer side effects, first-run service registrations and reboot-deferred writes fall outside the snapshot window.

This build
Licensing

Vanish is MIT licensed. This build carries no third-party runtime dependencies beyond Electron: the icon set is first-party and the typography is the operating system's own.

Restart as administrator?

Vanish is running in Audit Mode. It can list applications, scan for leftovers and produce reports, but it cannot uninstall, purge or restore anything until it is elevated.

Unlocker

Enter the file or folder that will not delete. Vanish asks the Windows Restart Manager which processes hold it, then offers a graceful close before anything is forced.
