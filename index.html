Machine Hygiene

Everything here reads only -- no finding on this screen can be removed by Vanish, in Audit Mode or Full Mode. It answers the question a disk-usage tool cannot: not how big a folder is, but what deleting it would cost you. Checks walk your user profile and can take a while on a large disk, which is why they run when you ask and not when you arrive.

System Clean

Each section looks for settings that point at a file no longer on this PC. Scanning only reads - it changes nothing, and works in Audit Mode. Anything you remove is moved to quarantine, where you can put it back.

Watch an install

Take a reading, run an installer yourself, then take a second reading. Vanish reports the difference: new folders, startup entries, services and uninstall entries. It reads only - it installs nothing and changes nothing.

Where your disk space went

Matches the folders in Program Files and your app data against the programs actually installed on this PC. Folders left behind by a program you no longer have are named as such; folders Vanish cannot explain are listed separately and never presented as rubbish. Reading only - nothing is removed here.

About

Vanish

-

A Windows uninstaller and clean-up tool that runs entirely on this PC. It shows you what it found, keeps a way back from everything it removes, and waits for you to decide.

Nothing is deleted straight away

Files are moved to quarantine, and registry entries are saved to a backup file before they are removed. You can put any of it back until you choose to delete it for good.

Useful before it is powerful

Without administrator rights, Vanish still lists, scans and explains. It never pretends it can remove something it cannot. Asking for those rights is a separate step you take.

Nothing about you or this PC ever leaves it

No tracking, no cloud lookups, no update checks, no telemetry of any kind. Even the icons and fonts come from this PC, so nothing is downloaded. That promise is absolute - it does not have an exception.

What that promise does not require is silence on the wire. There are exactly two things Vanish can put on the network, both in Network Activity, both only when you tap them, neither ever automatic or on a timer, and each agreed to separately the first time:

  • Ping - a single ICMP echo to the address shown, normally your own router. It carries nothing about you.
  • Measure line speed - about 5 seconds of downloading and 3 of uploading against speed.cloudflare.com, stopping sooner on a slow connection and never using more than 40 MB down or 10 MB up, to answer how fast the connection actually is. There is no way to learn that without using the connection. Cloudflare sees this PC's IP address and a few seconds of traffic; the data transferred is random bytes one way and discarded the other, so it carries nothing of yours. The result is shown and never saved, logged or sent anywhere.

Accepting one does not accept the other, and neither is on until you say so. Everything else in the app only reads what is already on this PC.

What it does not do

It is not an antivirus and will not tell you whether something is malicious. It also cannot promise to undo everything: changes an installer makes in the background, or that Windows finishes after a restart, happen outside what Vanish can record.

Restart as administrator?

Vanish is in Audit Mode. It can list your programs, scan for leftovers and show you what it found, but it cannot uninstall, remove or restore anything without administrator rights.
